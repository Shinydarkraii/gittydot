# GittyDot icon options

Generated with the built-in image generation tool on 2026-10-14, using the user's blue G / red Git crossbar sketch as a concept reference.

1. [Flat charcoal tile](../addons/gittydot/icon.png) — active plugin icon.
2. [Transparent symbol](02-transparent.png) — alternative for toolbar use without a tile.
3. [Beveled charcoal tile](03-beveled.png) — alternative with shallow depth.

The PNG artwork retains its original resolution and alpha. The plugin creates a texture sized to the editor DPI at runtime; it does not rewrite the original image. To choose another option, replace `icon.png` with the chosen PNG in both installations and restart the editor.
